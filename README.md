## About

This repository was created as part of my self-learning journey in software testing.  
The main goal was to practice:

- Setting up a Maven-based Java project
- Organizing test code using the **Page Object Model (POM)**
- Exploring basic structure for automated UI testing with Selenium and TestNG

This is a **learning project**. It is not a production-ready test suite.

---

## Tech Stack

- **Java**
- **Maven**
- **Selenium WebDriver** (practice setup)
- **TestNG** (practice setup)
